# GameZone-Jes-sL-pezGarc-a
Descripción:
Aplicación que gestiona las ventas de los productos de una tienda de videojuegos donde el empleado puede registrar las ventas, consultar la disponibilidad de stock de un producto en específico y su precio, además de consultar los tipos de productos que existen

Requisitos funcionales:
1.Gestión de productos
2.Gestión de categorías 
3.Gestionar las ventas de productos con sus respectivos clientes
4.Gestión de clientes
5.Gestión de empleados

¿Qué he usado?
Java (Lenguaje de programación)
MySQL (Gestor de Base de Datos)
JDBC (Conector a la base de datos)
